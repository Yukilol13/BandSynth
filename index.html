离线渲染 · 生成伴奏音频

使用 OfflineAudioContext 按谱面逐音符排程渲染，输出与实时播放一致。渲染速度通常快于曲速。

导出说明

  • 格式：WAV PCM 16bit 立体声 44.1kHz
  • 渲染源：有编曲内容时自动使用编曲页的当前内容（不必先试听）
  • 尾音：谱面结束后额外保留 2 秒混响/延迟尾
  • 分轨导出：每条音轨一个 WAV，带轨名前缀；鼓轨单独一轨
  • 勾选「只渲染循环区间」可按编曲页设的循环段导出

格式支持

手机录音m4a / aac / mp3 / wav / flac
视频文件mp4 / mov / m4v / webm（自动抽取音轨）
微信视频mp4/h.264 直接可用
微信语音AMR / SILK 私有格式需转码
其他容器mkv / wma / aiff 建议转 WAV
转码命令：ffmpeg -i in.mp4 -vn -ar 44100 -ac 2 out.wav
